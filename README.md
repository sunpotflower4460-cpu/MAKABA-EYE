# MAKABA-EYE — Stella Octangula Observatory

> This prototype is a visualisation device for observing the **stella octangula** —
> sometimes called "merkaba" in modern contexts — geometrically and numerically.
> The historical Merkavah relates to Ezekiel's vision and early Jewish mysticism,
> a distinct context. **This application does not equate the two.**

---

## What Is This?

MAKABA-EYE is a browser-based 3D observatory for the **stella octangula** (star tetrahedron).
It generates the geometry **analytically** from a single source of truth, validates all
geometric relationships numerically, and displays both the 3D figure and the underlying
numbers in the same interface.

This is not a spiritual tool. It is a geometry visualiser.

## Geometry Specification

All geometry is generated by `src/geometry/merkaba.ts`.

### Coordinate System

- Origin at `(0, 0, 0)`, scale parameter `s` (default `s = 1`)

### Outer Cube

8 vertices at all combinations of `(±s, ±s, ±s)`. Edge length = `2s`.

### Tetrahedron A

4 vertices from cube corners where **sign product = +1**:
```
(+s, +s, +s),  (+s, -s, -s),  (-s, +s, -s),  (-s, -s, +s)
```

### Tetrahedron B

4 vertices from cube corners where **sign product = −1**:
```
(-s, -s, -s),  (-s, +s, +s),  (+s, -s, +s),  (+s, +s, -s)
```

### Inner Octahedron

6 vertices at the face centres of the cube:
```
(±s, 0, 0),  (0, ±s, 0),  (0, 0, ±s)
```

This is the intersection of Tetrahedra A and B.

### Key Metrics (at s = 1)

| Quantity | Value |
|---|---|
| Cube edge | 2.000000 |
| Tetra edge | 2√2 ≈ 2.828427 |
| Octahedron edge | √2 ≈ 1.414214 |
| Dihedral angle | acos(1/3) ≈ 70.5288° |

See [`docs/geometry.md`](docs/geometry.md) for full specification including half-space forms.

## Validation

`src/geometry/validation.ts` runs 9 checks at startup (and on every scale change):

- Edge length equality (both tetrahedra)
- Shared centroid at origin
- All 8 vertices correspond to cube corners
- Inner octahedron vertex positions
- Dihedral angle = `acos(1/3)`
- Scale invariance
- Panel/scene data consistency

Results are shown in the **Geometry panel** and (optionally) in the **Validation overlay**.
Status is `Analytic + validated` when all checks pass.

## Historical Note

The word **Merkavah / Merkabah** (Hebrew: מֶרְכָּבָה) refers to the divine throne-chariot
in Ezekiel's vision (Ezekiel 1; 10) and became the central object of early Jewish
mysticism (Hekhalot/Merkabah literature, c. 3rd–7th century CE). This is a distinct
religious-historical concept, separate from the geometric star tetrahedron.

MAKABA-EYE visualises the geometry; it does not claim to represent the historical Merkavah.

See [`docs/context.md`](docs/context.md) for a fuller account of these four distinct layers.

## Known Limitations

- Transparent face rendering order is not CSG-correct (standard WebGL limitation)
- Vertex/edge labels may overlap on mobile at small screen sizes
- No postprocessing effects (bloom, etc.) — by design for performance and clarity
- WebGPU not used; WebGL only for maximum compatibility
